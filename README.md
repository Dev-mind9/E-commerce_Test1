# 🛒 Projet E-commerce - Team

## 📌 Description
Ce projet consiste à développer une application web e-commerce permettant aux utilisateurs de consulter des produits, les ajouter à un panier et simuler un processus d’achat.

L’objectif principal est d’apprendre :
- le développement web (HTML, CSS, JavaScript)
- le travail en équipe
- l’utilisation de GitHub (branches, commits, pull requests)

---

## 🎯 Objectifs
- Créer une page d’accueil
- Afficher une liste de produits
- Ajouter des produits au panier
- Structurer un projet en équipe
- Comprendre le workflow GitHub

## 🔄 Workflow (obligatoire)

1. Créer une branche
2. Travailler sur sa tâche
3. Faire un commit
4. Envoyer une Pull Request
5. Attendre validation avant fusion

⚠️ Ne jamais travailler directement sur `main`
