# 🛒 ShopElite - Boutique E-commerce Moderne

## 📌 Description
ShopElite est une application web e-commerce moderne et professionnelle développée avec les meilleures pratiques du développement web. L'application offre une expérience utilisateur exceptionnelle avec un design responsive, des fonctionnalités avancées de panier, et une architecture JavaScript moderne.

## 🎯 Fonctionnalités Principales

### 🏪 **Gestion des Produits**
- Catalogue de produits riche avec images, descriptions et prix
- Système de notation et avis clients
- Filtrage avancé par catégorie, prix et disponibilité
- Recherche en temps réel
- Tri par popularité, prix, notation

### 🛒 **Panier d'Achat Intelligent**
- Ajout/suppression d'articles en un clic
- Modification des quantités
- Calcul automatique des totaux
- Codes promo intégrés
- Options de livraison
- Persistance des données (localStorage)

### 🎨 **Design & UX**
- Design moderne et professionnel
- Interface entièrement responsive
- Animations fluides et transitions
- Mode sombre/clair cohérent
- Accessibilité WCAG 2.1

### 📱 **Responsive Design**
- Optimisé pour desktop, tablette et mobile
- Navigation mobile avec menu hamburger
- Grille adaptative des produits
- Interface tactile optimisée

## 🚀 Comment Utiliser

### **Installation**
1. Cloner le repository
2. Ouvrir `index.html` dans un navigateur moderne
3. L'application fonctionne entièrement en local

### **Navigation**
- **Accueil** : Découverte des produits populaires
- **Produits** : Catalogue complet avec filtres
- **Panier** : Gestion des achats
- **Recherche** : Fonctionnalité disponible dans le header

### **Fonctionnalités du Panier**
- Ajouter des produits depuis n'importe quelle page
- Modifier les quantités directement
- Appliquer des codes promo (WELCOME10, SAVE20, FLASH50)
- Calcul automatique des frais de port
- Paiement simulé
